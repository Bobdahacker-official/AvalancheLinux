AvalancheLinux 1.0 Summit introduces the Avalanche desktop applications, command-line tools, and graphical installer configuration.

## Downloads

- **avalanche-core_1.0-1_all.deb**: Avalanche Center, Software, Updates, Settings, the desktop session, and the `avalanche` command.
- **avalanche-installer_1.0-1_all.deb**: the Avalanche Calamares workflow, installer screens, and launcher for live images.
- **SHA256SUMS**: checksums for both packages.

Install the desktop applications on Debian 13:

```sh
sudo apt install ./avalanche-core_1.0-1_all.deb
```

Open **Avalanche Center** from the applications menu after installation.

## What’s new

- Browse application collections or search the package archive in Avalanche Software.
- Refresh package information and start upgrades from Avalanche Updates.
- Open display, network, sound, power, appearance, and keyboard controls from Avalanche Settings.
- Check services, free disk space, and package health with `avalanche doctor`.
- Install individual packages or collections with commands such as `avalanche install gimp` and `avalanche install @office`.
- Start an Avalanche desktop session with its own panel, welcome screen, login theme, and boot menu.
- Build a live image with the Avalanche Calamares installer. Its workflow covers disk setup, accounts, filesystem deployment, and bootloader installation.

## Build an image

This release contains packages and source. The earlier base ISO predates the Avalanche applications, so it is kept separate from this release.

Follow the [build instructions](https://github.com/Bobdahacker-official/AvalancheLinux/blob/v1.0.0/README.md#build-a-live-image) to create an image from this version. Image builds are manual; publishing these packages doesn’t start an image build or VM tests.

Debian 13 provides the compatible package archive. Upstream licenses and copyright notices are preserved.
